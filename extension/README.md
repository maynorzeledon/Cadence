# SteadyType

## Install in Chrome

1. Extract SteadyType.zip if you downloaded the ZIP.
2. Open chrome://extensions in Chrome and enable Developer mode.
3. Choose Load unpacked and select the steadytype folder containing manifest.json.
4. Click a text field on a web page, open SteadyType from the extensions menu, enter your text, and click Start.

## Features

- Plain text types at the chosen WPM with slight timing variation and optional sentence pauses.
- Pause, resume, or stop from the popup. Press Escape on the page to stop.
- Personal pace uses a sample you type in the popup to estimate speed and timing variation. The sample is cleared after calibration. Your pace settings and draft are stored locally.
- Markdown formatting inserts the formatted result in one operation in a compatible rich-text field. It supports headings, ordered and unordered lists, bold, italics, and inline code.

SteadyType works with standard text inputs, textareas, and many contenteditable elements in the main page. Custom editors such as Google Docs and Word Online, fields inside iframes, and browser settings pages are outside this release's scope.
